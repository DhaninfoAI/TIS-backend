Return ONLY questions that need the reviewer's attention:
- kind "differ": photos, the narrative or other answers show the current answer is wrong. suggested must be

  vacant-building utilities answered; access to all areas "Yes" but the photo review list has no roof

  1965–1975; Zinsco/Stab-Lok "free of" while a panel photo shows one; housekeeping "Yes" while photos show
  clutter.

Before suggesting a different answer, check three things:
1. Direction. Many questions are worded so that "Yes" is good ("free of…", "in good condition", "satisfactory",
   "smooth and even", "to code"); others so that "Yes" is a problem ("Any…?", "Any history of…?"). Say in
   evidenceShows whether your evidence shows a problem ("problem"), shows the condition is fine ("no_problem"), or
   neither ("unclear"), and make the suggested answer mean exactly that. Housekeeping with clutter → "No".
2. Subject. The evidence must be about the exact subject of the question. Housekeeping = accumulated refuse,
   debris, clutter, combustible storage; NOT building damage, missing signs, missing mats, cracks. Propane/BBQ =
   a grill, BBQ, fire pit or propane tank; NOT pool signage. Electrical = wiring, panels, breakers, outlets; NOT
   slip mats. FPE / Zinsco = only when a photo description or the narrative names the brand. Brick veneer = only
   from the brick pattern, weep holes or the narrative, never from the ISO class alone. If the evidence fits a
   different question, put it on that question or leave it out.
3. Certainty. Only change an answer on direct evidence. "May indicate", "could be", "typically", "likely" are not
   evidence: leave such questions out.

ISO construction cheat sheet: ISO 1 Frame = combustible walls/roof (brick veneer over wood frame is still
ISO 1; veneer shows only "stretcher" bricks, weep holes, shallow window depth < 8 in). ISO 2 Joisted
Masonry = masonry walls (header bricks in the pattern, deep openings ≥ 8 in) with wood joists/roof.
ISO 3 Non-combustible, ISO 4 Masonry Non-combustible, ISO 5 Modified Fire Resistive, ISO 6 Fire Resistive.
